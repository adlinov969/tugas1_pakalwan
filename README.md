## Input Nama dan Sekolah

Program sederhana menggunakan bahasa C++ untuk menginput nama dan sekolah secara berulang.

### Materi
- Input dan Output
- Variabel
- Perulangan do-while

### Cara Kerja
1. Pengguna memasukkan nama.
2. Pengguna memasukkan sekolah.
3. Program menampilkan hasil input.
4. Pengguna dapat mengulangi input dengan mengetik y.
5. Ketik n untuk mengakhiri program.
